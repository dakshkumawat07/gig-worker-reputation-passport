# Gig Worker Reputation Passport

A portable and cryptographically verifiable reputation passport for gig workers, developed for the Craft N Code Rajasthan 2026 hackathon.

## Problem

Gig workers often build reputation within individual platforms, making it difficult to carry verified work history and trust information across different platforms.

## Proposed Solution

Our project demonstrates a portable reputation passport that allows a gig worker's reputation to be issued, transferred, and cryptographically verified across simulated platforms.

## Core Features

- Worker reputation profile
- Portable reputation passport
- Digitally signed reputation data
- Passport verification
- Tamper detection
- Simulated Platform A → Platform B transfer

## Tech Stack

- React
- Node.js
- Express
- JSON/local storage
- Node.js crypto
